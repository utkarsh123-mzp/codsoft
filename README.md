🔍 Project Overview
This is a command-line based To-Do List Application designed to help users manage their daily tasks efficiently. The project focuses on core Python concepts like file handling, list manipulation, and user input validation.


 Key Features :
Add Tasks: Quickly add new tasks to your list.

View Tasks: Display all current tasks in a clean, tabular format.

Update Tasks: Modify existing tasks if plans change.

Delete Tasks: Remove completed or unwanted tasks.

Data Persistence: All tasks are automatically saved to a .txt file, so your data is safe even after closing the program.

 Technologies Used :

Language: Python 3.x 

Modules: os, sys
